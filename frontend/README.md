# frontend

Vite + React 19 + TypeScript + Mantine 9, TanStack Query, React Router.
Standards: `.codex/skills/frontend-standards/SKILL.md`.

## Run

```bash
npm ci
npm run dev        # http://localhost:5300, proxies /api to http://localhost:8300
```

## Layout

```text
src/
  main.tsx                 entry
  app/                     composition only (may import features via @/features/<name>)
    App.tsx                UiProvider, QueryClientProvider, BrowserRouter
    AppRoutes.tsx          resident routes, lazy /admin/* area, lazy /design-system
    residentRoutes.tsx     resident pages: add one line { path, element } per page
    adminRoutes.tsx        admin pages (lazy, relative to /admin): one line each, `nav` adds a menu item
    admin/                 AdminArea (AdminShell + admin routes, its own chunk), placeholders
    resident/              placeholder home, not-found page
  features/<name>/         one folder per feature + index.ts + README.md + tests
  shared/api/              client.ts (generated by `make api`), api.ts (the instance), types.ts aliases
  shared/ui/               design system: tokens, theme, primitives (see shared/ui/README.md)
  test/                    vitest setup and renderWithProviders
e2e/                       Playwright specs against the running app
eslint-rules/              local policy rules (feature boundaries, API contract types, no raw styles)
```

All visual code lives in `src/shared/ui`; features compose `@/shared/ui` primitives
(admin-only ones from `@/shared/ui/admin`) and never import `@mantine/core`, CSS or
style props (lint rule `local/no-raw-styles`). Gallery: `/design-system`.

## Scripts

| Script | Does |
| --- | --- |
| `npm run lint` | ESLint, including local policy rules |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run test:run` | Vitest once |
| `npm run build` | typecheck + production build |
| `npm run test:e2e` | Playwright against `E2E_BASE_URL` (default `http://localhost:5300`); first run `npx playwright install chromium` |

`Dockerfile` has a `dev` target (Vite) and a `production` target (static build
served by nginx). Its `/api` proxy target in `nginx.conf` is a placeholder until the
deploy host is chosen (`docs/deployment.md`).
